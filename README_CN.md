# DynaFlux 中文说明

DynaFlux 是一个面向交通流量多步预测的多尺度动态图学习框架。其核心目标是在同一网络中同时表达交通流的短期变化、日周期与周周期，并将远距离节点之间的流量相似关系与近距离道路拓扑关系联合建模。

## 方法结构

输入由三组对齐窗口构成：预测时刻前一小时、前一日对应的一小时、前一周对应的一小时。每个窗口包含 12 个 5 分钟时间帧，并使用独立但同构的时间编码分支提取特征。时间编码器由流量投影、日内位置、星期位置、节点自适应嵌入以及多头自注意力组成。

全局动态图分支对每个节点的时间特征序列进行展平，计算节点对之间的欧氏距离，并使用 `1/(1+d)` 转换为流量相似度。随后构造归一化图拉普拉斯矩阵，对其进行特征分解，取最小特征值对应的特征向量执行 K-means，得到反映远距离流量模式相似性的节点分组图。

局部图分支从道路边信息建立加权拓扑图，使用 Louvain 社区发现获得区域划分，再使用拓扑掩码图注意力机制学习邻居节点的重要性。全局图与局部图按元素交互并进行 Softmax 归一化，形成多尺度动态关联矩阵，用于聚合节点特征。

自适应卷积模块先用 MLP 融合交通残差特征与多尺度图聚合特征，再并行执行扩张因果卷积与普通因果卷积。门控信号定义为 `G = sigmoid(X1 + X2)`，最终输出为 `G ⊙ X1 + (1-G) ⊙ X2`，并保留残差连接以提高训练稳定性。

三个周期分支最后在节点维度保持对齐，在特征维度拼接，通过回归头一次性输出未来 12 个时间步。

## 数据预处理

默认采用以下流程：将零值与 NaN 视为缺失位置；使用节点/特征统计量进行插补；支持 Robust Scaling 与 Z-score 两种标准化方式；使用长度 12 的滑动窗口构造样本；默认训练集、验证集、测试集按 6:2:2 划分。PEMS08 配置中 1 天为 288 个时间步，1 周为 2016 个时间步。

## 训练

```bash
pip install -r requirements.txt
pip install -e .
python scripts/train.py --config configs/pems08.yaml
```

训练输出位于 `outputs/pems08/`，包括最佳权重、最后权重、训练历史、评估指标、缩放参数与空间图缓存。

## 评估

```bash
python scripts/evaluate.py \
  --config configs/pems08.yaml \
  --checkpoint outputs/pems08/best.pt \
  --graph outputs/pems08/graph.npz \
  --scaler outputs/pems08/scaler.npz
```

评估结果包含 15、30、45、60 分钟预测时效下的 MAE、RMSE、MAPE 与 R²，以及全部 12 步的平均指标。

## 无数据快速检查

```bash
python scripts/demo_synthetic.py
pytest -q
```

该模式会生成具有日周期与周周期的合成交通序列，用于确认模型前向传播、动态图构建和输出维度是否正常。
