# DynaFlux 算法说明

## 1. 多周期输入

设基础交通流量张量为 `X ∈ R^(T×N×C)`。对每个预测起点 `t` 构造三个长度为 `L=12` 的窗口：

- 小时窗口：`X[t-L:t]`
- 日窗口：`X[t-288-L:t-288]`
- 周窗口：`X[t-2016-L:t-2016]`

目标为 `Y = X[t:t+12]`。

## 2. 时间编码

每个周期分支将交通流特征、日内位置、星期位置、节点嵌入和时间步嵌入进行融合，随后对每个节点独立执行多头时间自注意力。默认隐藏维度 64、3 层编码器、4 个注意力头。

## 3. 全局动态流量图

对编码后的节点序列进行展平。节点 `i,j` 的动态距离定义为：

`d(i,j) = ||x_i - x_j||_2`

相似度：

`s(i,j) = 1 / (1 + d(i,j))`

根据相似矩阵 `S` 构造对称归一化拉普拉斯：

`L = I - D^(-1/2) S D^(-1/2)`

对 `L` 做特征分解，取最小的 `K` 个特征向量组成谱嵌入并执行 K-means。属于同一类别的节点形成全局关联矩阵 `A_G`。

## 4. 局部空间拓扑图

道路距离通过高斯核转为边亲和度，并使用阈值过滤弱连接。Louvain 社区发现提供区域结构，图注意力层在拓扑与社区掩码约束下学习局部关联矩阵 `A_L`。

## 5. 多尺度融合

全局与局部图执行按元素交互：

`A_M = softmax(A_G ⊙ A_L)`

随后使用 `A_M` 对节点特征进行加权聚合，得到多尺度空间特征 `X_MS`。

## 6. 自适应门控卷积

交通残差特征与 `X_MS` 经 MLP 融合为 `X_ST`。两条时间卷积分支分别为扩张因果卷积与普通因果卷积：

`X1 = Conv_d(X_ST)`

`X2 = Conv(X_ST) ⊙ (1 + ε), ε ~ U(-0.1, 0.1)`

门控信号：

`G = sigmoid(X1 + X2)`

融合输出：

`X_AC = G ⊙ X1 + (1-G) ⊙ X2`

实现中在该结果外增加残差连接和 LayerNorm，用于稳定优化。

## 7. 多步预测

三个周期分支取最后一个时间位置的节点表示，在特征维拼接后由 MLP 回归头输出 `12` 个未来时间步。训练使用 Huber Loss，默认 Adam 学习率 `1e-3`，批量大小 `16`，梯度裁剪阈值 `5.0`。
